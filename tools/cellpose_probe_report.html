Do image features improve association?

Every new proposal receives freshly sampled 32-dimensional TemporalUNet features. The node transformer sees the full bank. A fixed 15 µm motion gate applies to all controls. Geometry uses negative physical distance. Zero-image features preserve positions, coordinates and the trained head; this ablation is not a separately trained model. What the provenance evidence establishes
  • The exact secondary weight matches the released snapshot manifest. All six snapshot file hashes pass. It supplies 80% of the incumbent detector-logit mixture; association uses a different blend.
  • Its records contain 400 epochs; epoch 381 was selected with monitoring edge accuracy × detected-node recall of 0.9779747766. That value is not the competition metric.
  • Training source is available in the released packs. The shipped trainer reads the overlapping train/test lists literally. Some facilities recorded in the snapshot metadata are absent, so exact historical reproduction remains incomplete.
  • The primary checkpoint’s training split and history are not equivalently documented. A 50ep dataset slug is not proof of its training horizon.
  • The organizer states that scored test embryo IDs do not overlap training embryo IDs. Training on public data and evaluating locally on those same clips are separate from accessing hidden test labels.

Protocol and limits

The original pilot used frames 25 and 75. Its unexecuted embedding-plan draft was corrected by adding frames 26 and 76 before evaluation. The final panel contains twelve adjacent pairs across six reused clips. Model predictions, union banks and native scores were locked before opening the evaluation labels. No new fitting, label-based filtering or candidate-budget tuning was performed.

The previous 400-frame results belong to a different cohort: DINO-B R3 71.76%, R7 95.89%; incumbent R3 85.82%, R7 99.50%. Compare new models against the same 24-frame baseline shown here.

More proposals can improve endpoint availability while adding duplicate alternatives and changing the final count penalty. Complete-clip tracking must determine the resulting score. An independent-embryo test also requires an encoder trained with that embryo excluded from the start; retraining only the last head does not remove encoder exposure.
