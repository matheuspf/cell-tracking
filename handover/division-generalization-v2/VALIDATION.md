# Validation and decision rules

## Honest evidence levels

Main practical comparison: source-trained module on P0's exposed observations,
not clean OOF. Both public embryos have already been inspected repeatedly; the
released detector and historical teachers carry upstream label exposure.
Training a new raw-scene model from scratch does not remove exposure from the
candidate/observation pipeline. No local result implies a hidden-LB result.

Direct labels, calibration, normalization choices and mining use source 44b6 when
predicting 6bba, and vice versa. Preserve separate processes/manifests. Previously
observed all-199 failures motivate this NEW study but cannot become a new independent
holdout. Do not use old target error tables to mine examples for that direction.

Group acquisition/lineage/overlapping clips and all alternative time anchors
before splitting source fit/calibration. Preserve known exact-frame overlap unions;
read metadata before assuming clip independence. Purge at least the complete
image/graph context (minimum nine frames, larger if any inherited dependency reads
farther). Missing global acquisition offsets must remain an explicit limitation.
No random split of pair rows or crops from one event across folds.

Where independently certified inner source groups exist, use them. Otherwise
use the prior deterministic source groups with overlap unions and disclose that
the split is exploratory. Do not quietly fall back to fitting calibration on every
source label and call it held-out. With too few positive calibration groups, use
grouped out-of-fit predictions for the SMALL head when feasible, keeping image
encoder exposure clearly separate. If this is infeasible, retain fixed uncalibrated
relative gains at zero with explicit `calibration_unestablished`, or report a
resubstitution diagnostic separately; it cannot establish reliability or clean
transfer. Do not invent biological priors from sparse counts.

Clean upstream source-only models, if now actually completed and verified, may
support one additional transfer check of the source-selected module. Do not
restart/wait for old 400-epoch jobs as a prerequisite or call intermediate progress
a completed clean comparison. No external downloads are required for this plan.

## Training adequacy versus success

Every main directional model needs 4096 actual JOINT optimizer updates (or a
clearly incomplete/resumable status), representative negative-only event groups,
measured loss/gradient histories, source group coverage, literal-zero path proof,
label/scorer parity and full source screens. The helper validates a receipt's
schema, not the truth of these assertions; verify the artifacts and hashes.
A finite loss or 4096 updates does not itself prove convergence or generalization.

Log event/risk/identity losses separately on FIXED source diagnostic panels and
fit data. The old first/final loss compared different training phases; do not use
that as a convergence curve. Check source overfit fixtures before production;
record whether output collapse, wrong masking or no-op dominance occurs. A model
that rejects everything is safe but not an improvement and not a successful
mitosis recognizer. An FP reduction obtained by losing all new TP is not enough.

The only duration extension is the source-only rule in PLAN.md. Define a common
checkpoint/application selection rule before target access: among eligible
checkpoints, maximize full source calibration score with no regression against
source P0; tie-break on fewer lost supported edges, then earlier checkpoint.
Record all source checkpoints and calibration support. Selection on a reused
source split remains exploratory. Freeze each directional package and the common
arm nomination before seeing the new target matrix. No changes based on target
precision/recall curves or interesting visual cases.

## Target comparisons and recommendation

Score all 199 complete clips with the pinned official revision
075fc5f5a52d11077f9dc2b074644618f26939e2. Aggregate per-clip adjusted edge terms
with exact official weights and micro division counts. Do not average embryo or
clip scores. Every nominated model needs complete per-clip receipts and independent
aggregation verification, not a six-clip result or the old upstream proxy metric.

Use both seeds 20260916/314159 and both directions; no lucky-seed replacement.
Compare matched uniform/mined branches with their common-prefix relationship
stated. The primary replication target is the selected module, not an ensemble.
Report source-failed or unfinished arms with their actual status and no invented
target score. Do not skip the main adequate-training attempts just because G30
fails. Source qualification controls expensive target export, not implementation.

To recommend a replacement candidate: correctness/fresh-image gates pass; positive
pooled delta over P0 in BOTH seeds; nonnegative full-score delta in EACH embryo in
BOTH seeds; primary seed exceeds C4_m6; no undisclosed node changes or lost regions;
and all required matched controls exist. To claim an advantage specifically from
mining, require its delta over the uniform control to be positive in both seeds
and report each embryo rather than attributing all combined changes to mining.

A score >=0.95 is the requested target, not an acceptance threshold that authorizes
searching until it appears. Report `target_met` separately per seed. A headline
robust >=0.95 result requires both complete seeds to meet it and the recommendation
gates above. One 0.95 seed is an isolated result, not a replicated achievement.
Smaller reliable gains remain measurable but do not fulfil the target. Keep P0
as the production default; recommendation and adoption are separate actions.

Within permitted complete event edits, some previously correct links can change;
report all losses and full metric tradeoffs. Outside those edits, preservation
must be exact. Do not demand impossible zero biological change and then tune only
abstention. No per-embryo policy tweaks, GT-matched-only inference or removal of
all unannotated predictions is allowed.

## Required reporting

First table: P0, C4_m6, G30 control, main uniform/mined nominees and replications;
pooled and per-embryo score; delta vs BOTH references; TP/FP/FN for edges/divisions;
raw/adjusted edge terms; selected/matched node counts; unchanged node hashes.
Then recovered AND lost GT edge/division identities, FP added AND removed,
early/on-time/late split outcomes, competing-owner errors and error partitions.
Do not sum overlapping biological error categories.

Stage attribution includes candidate availability, trained score, calibration,
max-selected action, ownership/protection, conflict/solver and final official
local-window result. Display actual raw scenes for all new recovered divisions,
all lost divisions, and a deterministic sample of false forks. Visual review is
post-freeze diagnosis, not a target-refit loop. Use source-fixed density/depth/
intensity/boundary strata, and distinguish whole-clip matching from local division
matching. No clip bootstrap presented as independent-embryo certainty.

Report the current source-label witnesses as feasibility only. Arithmetic such
as +37 TP with constant FP/edge term is not an achievable forecast. The scientific
question is whether learned decisions approach those witnesses on source transfer.

## Runtime and delivery

One GPU worker, separate bounded CPU I/O; one BLAS thread per worker; total 16.
Run a complete crowded clip early for a realistic inference projection. Do not
export all failed families just to fill the old matrix. Preserve replication and
fresh-proof resource reservations. Report actual exclusive GPU-lease wall time,
wait time, kernel/profiler estimates where available, total process-tree RSS and
whole-device memory; these are different quantities.

Measure cold inference on two renamed full clips, explicitly routed source model,
from images through original P0 then this module. Deny GT, historical prediction
caches and network from process startup. Require exact candidate GEFF/CSV parity
with scored artifacts; allow only current-run image/code/model-hashed caches.
A local 4090 time is not a Kaggle-runtime guarantee. Refresh official runtime/
external-model requirements before packaging, with no shared-env upgrades.

Required concise committed artifacts: STATUS.json, REPORT.md, CONTINUATION.md,
input/exposure/split manifests, execution_lock.json, sampling_audit.json,
training_curves.csv, training_receipts.json, source_scores.csv,
calibration_audit.json, action_label_parity.json, stage_attribution.json,
scores.csv, per_embryo_scores.csv, error_transitions.csv, replication.json,
resource.json and validation.json. Heavy images, labels, graphs, caches and weights
remain under ignored work/division-generalization-v2; commit their hashes and
portable reconstruction instructions. Missing values are null with reasons.
Do not modify past results, production defaults or publish/submit anything.
