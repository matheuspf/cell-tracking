03 / Think in graphs

Identity is a path. Division is a fork.

A node is one cell detection at one time. An edge says the source continues as the target. A dividing cell has two daughter branches. There is no separate division column in the CSV.

Teaching simulation · fully annotated toy graph
Predicted temporal linkWrong added linkClick a node to inspect its row

All toy nodes match exactly; predicted and estimated node counts are equal. This illustrates simple edge/fork errors. It does not reproduce the official division-window matcher.

Node IDs are not track IDs

IDs identify detections within a dataset. A continuing cell has a new node at the next timepoint. Its identity comes from the edge linking those two nodes.

A strict one-to-one assignment can follow movement but cannot express a split. Division recovery needs a way to retain two outgoing links from a parent.

Model-design implication: improve your detector and linker together. A missed detection can break neighboring edges; a confident wrong link can join unrelated cell histories.

04 / The score lab

Get the edges right. Count the forks.

The leaderboard combines an adjusted edge Jaccard and a smaller division term. This is a graph metric after spatial matching—not a mask IoU or a detection mAP.

score = adjusted edge Jaccard + 0.1 × division Jaccard
One-sample arithmetic sandbox

Move the terms. Watch the tradeoff.

Enter already-matched edge counts. Changing these numbers does not generate or evaluate a graph.

The sliders hold other terms fixed to isolate arithmetic. In a real pipeline, removing nodes can also reduce edge recall and division recovery.

What enters those counts?

First match nodes. At each timepoint, one-to-one optimal assignment pairs predicted and annotated centers within 7 µm, using physical distance.

Then match edges. A TP has both endpoints matched to a labeled edge. An unrecovered labeled edge is an FN. In sparse regions, many predictions are ignored; competing links at annotated endpoints can be FPs.

Adjust for detection count. Let r = predicted / estimated total nodes:

J = TP / (TP + FP + FN)
adjusted J = max(0, J × [1 − 0.1(r − 1)])
Yes, a score can exceed 1. The count multiplier is greater than one when r < 1. Even without that, the division term adds up to 0.1. This is not a percentage.

Divisions: local, directed parent/daughter evidence matters. Merely connecting tracks into one large component does not establish correct mitosis. Timing tolerance includes a one-frame early/late fork subject to the matching rules.

Across clips, adjusted edge values are weighted by each clip’s TP+FP+FN. Division counts are summed before calculating their Jaccard. Do not average per-clip combined scores equally.

Pinned organizer metric details ↗Official evaluation

7 µm is not 7 voxels

Isolated node-pair distance
d = √[(1.625 Δz)² + (0.40625 Δy)² + (0.40625 Δx)²]

7 µm is the evaluator’s matching threshold, not a mandated linking radius between frames. Within the threshold, another prediction may still win the one-to-one assignment.

Equal voxel axes shown. The same physical tolerance is about 17.23 X/Y voxels or 4.31 Z voxels. A Z voxel spans four times the physical distance of an X/Y voxel.

Design distance gates, nonmaximum suppression, and augmentations in physical space. A 90° swap of Z and X is not physically equivalent without accounting for this spacing.

A validation plan I would trust first

1. Hold out an embryo, in both directions. Train on 44b6 and validate on 6bba, then reverse. Track both outcomes; the two folds have unequal training sizes.

2. Retain per-embryo diagnostics. Report edge TP/FP/FN, adjusted edge Jaccard, division counts, detection count ratio, and runtime. Also calculate the official aggregate over held-out predictions.

3. Treat two groups as limited evidence. A gain on one embryo is not strong evidence of generalization. Inspect whether it survives the other holdout and different density/depth/time regions.

4. Tune on validation, inspect the public LB cautiously. Fix folds and scorer version before sweeping thresholds. Avoid repeatedly changing the experiment to explain one public score.

Recommendation, not an organizer-prescribed fold: embryo holdout directly tests the stated train/test separation. Within-embryo splits can still help debug optimization.

06 / Build & submit

Make the whole loop work first.

Start with one held-out clip and the official scorer. Then improve detection, association, and division recovery against the same validation setup.

Organizer starting point

The released baseline is useful scaffolding

The organizer repository couples a temporal 3D U-Net detector with a transformer for pairwise association. Its training uses sparse edge supervision. It also supplies evaluation and CSV↔GEFF utilities.

Reproduce its evaluation first. Treat longer training, stronger center proposals, better association, and explicit division handling as hypotheses to test, not guaranteed gains.

Open pinned baseline & scorer ↗
One easy local scoring trap: the baseline evaluator scores dataset names found in both prediction and GT directories. Check that this intersection equals your complete intended validation split.

Training on incomplete annotations

Start by understanding the baseline’s supervision mask. Unannotated cells need not be background. Possible experiments include supervising known trajectories, teacher-generated candidates, or accessible external/pretrained resources.

Keep pseudo-label generation and any fitted preprocessing inside each training fold. Diagnose sensitivity to detection threshold and predicted counts separately from association errors.

The official code page allows freely and publicly available external data and pretrained models. Check the detailed rules and any resource-specific organizer clarification before relying on an external source.

The ensembling twist: node IDs are arbitrary. Combine aligned detection maps, center proposals, or association scores, then reconstruct a valid graph. Averaging CSV rows does not preserve cell identity. Validate any fusion gain against its extra inference and linking cost.
