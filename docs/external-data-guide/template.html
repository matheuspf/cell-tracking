02

What the competition actually asks for

For each 3D video, detect cell centres and connect them through time. A cell division creates two daughter branches in the tracking graph.

1 · Image volumeUsually 100 timepoints × 64 Z × 256 Y × 256 X. Fluorescence intensity, uint16.
→
2 · Centre detectionsOne node per detected cell and timepoint: ID, t, z, y, x.
→
3 · Temporal graphDirected source → target links between adjacent frames, including daughter links.
score = adjusted_edge_jaccard + 0.1 × division_jaccard

The metric matches centres within 7 µm, evaluates temporal links, and checks local division topology. The 7 µm tolerance is for matching predictions to annotations; it does not set a tracking search radius. Official data format · Pinned metric description

Real labels are sparse. Our 199 local training samples contain 133,318 annotated nodes and 151 annotated division parents, across two embryos. This is about 2.8% of the estimated cells. Unmarked image regions are not reliable background negatives. The forum’s approximate 304 divisions uses a different or unverified count; we should use the measured graph and avoid inferring a real division frequency from sparse labels. Local audit.

The coordinate fix that matters

Sequence images are 64 × 64 × 64, while their original node coordinates still refer to a 64 × 256 × 256 grid. Divide Y and X by four; keep Z unchanged. Static images use the full native grid.

“Pooled” below means stride sampling [:, ::4, ::4], not block averaging. This is optional model preprocessing. The competition still uses native coordinates.

A division is a graph fork

This actual example from seq_0000 links node 479 at t = 2 to daughters 700 and 701 at t = 3.

The original field called track_id is shared by daughters: it identifies a clone or lineage. It is not a unique cell trajectory. The preparation preserves that field and derives separate tracklet IDs that break at divisions.

A tracklet is a continuous path between a birth, division or endpoint. Last-frame cells have no observed future; the loader masks them out of division-negative targets.

What the network would learn

A centre detector can learn a high response around each labelled point. We use a Gaussian width of 2 µm for this illustration. The width is a training choice; changing it changes the target, not the biological annotation.

Why this is not a segmentation mask

A heatmap does not assign every foreground voxel to a cell or trace its boundary. Dense synthetic centres can support this target. Sparse real centres need a loss that handles missing labels rather than declaring every unmarked region negative.

A labelled division in successive images

The same crop and contrast are used at every timepoint. Markers identify one selected lineage from the source graph, amid neighbouring fluorescent cells. The images give context; the supplied graph establishes the parent and daughter relationships.

Zoo: what the conversion does, and what is still uncertain

The original Zarr stores are viewer exports. The adapter reads time and raw Z/Y/X coordinates from tracks_to_points, extracts direct parent-track metadata from tracks_to_tracks, then connects consecutive observations and parent endpoints to daughter starts. All six converted stores passed adjacency and parent-consistency checks; the ascidian and worm reconstructions also match their original CSVs exactly.

tracks_to_tracks stores lineage reachability, so treating every entry as a temporal edge would invent links. The divisions display attribute holds hex colours, not a binary target. We derive forks from edges instead.

Coordinates remain in source units; display metadata is not proof of physical calibration. Species-specific voxel scale, time cadence and quality checks are still needed before transfer. Tracking results are not assumed to be manually verified ground truth. Radius and the other original viewer attributes remain in the source archive; the prepared graphs focus on positions and relationships.

Pinned export implementation · Original attribute inventory

RIKEN: labels, units and the limit of our inspection

For animal C, positions are in micrometres and consecutive frames are 90 seconds apart. The 14 features describe two fluorescence measurements, six bounding-box coordinates and six FWHM coordinates. These are measurements of a nucleus; they do not provide a dense segmentation mask.

The HDF5 measurement IDs are frame-specific identifiers. We found no explicit cross-time identity or parent field in the inspected sample. Nearest-neighbour matching would create pseudo-labels, not recover verified lineage labels.

We audited animal C’s full structure and counts and exported its first 10 frames. The other six archives are downloaded and inventoried, but their labels have not been audited in the same detail. 05

A practical training sequence

Establish a real-data baseline and a held-out embryo

Use embryo 44b6 (71 samples) for initial training and 6bba (128) for validation. Keep all fields and frames of an embryo together. Evaluate centres, links and divisions with the official sparse-label metric; do not treat all unlabeled cells as false detections.

Pretrain detection on the synthetic images, then fine-tune

Use static volumes and sequence frames to predict centre heatmaps or points. The loader can generate Gaussian centre targets. Add realistic intensity and spatial augmentation with the same transform applied to labels. Adapt to real images using a loss that accounts for missing annotations.

Learn temporal links and divisions from the synthetic graph

Supervise motion, link choices and parent-to-daughter branching. Synthetic clips are only six frames long and contain many deliberately sampled divisions. Measure the benefit on the held-out real embryo; tune sampling and thresholds there, rather than copying a claimed real division prior.

Add calibrated Zoo trajectories as a separate experiment

Start with zebrafish for the closest species match. After checking units, timing and tracking quality, test trajectory pretraining or realistic detection noise. Keep each source’s contribution measurable. RIKEN-driven rendering is a later project because image generation and verified correspondence are not supplied.

Calibration affects the split. The published generator fits density and tissue shape on ten videos from the first sorted embryo (44b6 here). Holding out 6bba avoids reusing those calibration videos. Fixed motion and rendering settings need a provenance audit before claiming complete fold isolation. Reversing the embryo split requires recalibration from that training fold.

Preparation is complete; no training or transfer-gain experiment has been run. Synthetic division parents are 4.07% of all synthetic sequence nodes, a descriptive count with final-frame censoring—not a calibrated probability of division. Archived generator.

What to check before calling an adaptation successful

Keep image transforms and labels together

A spatial crop, flip or resampling operation must transform every affected point. Preserve node IDs when transforming coordinates; when removing nodes, filter edges and reconsider division targets whose daughter branches were cut away.

Separate errors in detection and association

First check whether centres align in the image grid and physical space. Then check the graph endpoints and division branches. A correct linker cannot recover a missing daughter that the detector never proposed.

Test transfer on a whole real embryo

Compare a real-data baseline against the same pipeline with synthetic pretraining, then add Zoo data as another controlled experiment. Keep the real validation split fixed and report edge and division contributions separately.

Treat unseen futures as unknown

The last frame cannot show a later division. A cropped or incomplete track can also end without proving that a cell died or stayed undivided. Mask unavailable targets instead of converting them into negative examples.

Load a training sample in Python

Run from this guide’s directory with NumPy installed. The loader returns float32 images in [0,1]; it applies stride sampling only to native static images. The sequence images are already on the sampled grid.

from data_adapter import load_synthetic, points_to_heatmap

sample = load_synthetic("seq_0000")
image = sample["image"][0]                  # Z,Y,X = 64,64,64
points = sample["zyx_image"][sample["t"] == 0]
target = points_to_heatmap(
    image.shape, points, sample["voxel_um_zyx"], sigma_um=2.0
)
edges = sample["edges"]                     # source/target node indices
known = sample["division_target_observed"]  # excludes the final frame
division_target = sample["is_division_parent"]

The heatmap width is a training choice. The loader supports source_root=... if you move the original biohub_synthetic folder. Setup and reproduction instructions · Pinned preparation dependencies.

How these labels connect to the submission format

External labels train a model. The model must then predict every hidden test video. The final CSV uses native integer Z/Y/X coordinates and the exact test folder basename in dataset. Predictions made on the sampled grid need Y/X multiplied by four before rounding.
