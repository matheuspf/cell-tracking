# Notebooks

Keep original analysis notebooks here. Downloaded Kaggle notebook snapshots belong
in ignored subdirectories, with their source URL and version recorded locally.
Read inputs through `data/` or the canonical `/kaggle/input/competitions/` path;
write generated outputs to `/kaggle/working/cell-tracking`.

The three selected public notebooks live under
`/kaggle/notebooks/biohub-cell-tracking-during-development`, exposed locally as
the ignored `downloaded` symlink. Runnable copies are directly in `/kaggle/working`.
See [the notebook setup guide](../docs/notebooks.md) for scores, versions, and runtime.
